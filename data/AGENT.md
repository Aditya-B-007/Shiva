# AGENT.md — `data/`

## Purpose
Contains all raw inputs consumed by the training pipeline. Nothing in this folder is generated by the code — you supply it.

---

## Files

### `data.txt`
Raw text corpus used to **train the BPE tokenizer**.
- One sentence or paragraph per line (blank lines are skipped)
- Consumed by `BPETokenizer.train_from_file(TOKENIZER_RAW_DATA, target_vocab_size=500)`
- Only needed if `model_artifacts/tokenizer/tokenizer.json` does not already exist
- If the tokenizer JSON is present, this file is not read during training

### `train_dataset.jsonl`
Preference dataset for **Stage 1 DPO** and **Stage 2 RLCD** training.
- One JSON object per line, no trailing commas
- Currently 7 samples (medical, infrastructure, drone, robotics, finance, etc.)

**Required schema per line:**
```json
{
  "scenario":   "<string — the situation description>",
  "options":    ["<action 1>", "<action 2>", ...],   // min 2, max 32 strings
  "preferred":  "<string — must be one of options>",
  "rejected":   "<string — must be one of options, different from preferred>"
}
```

**Example:**
```json
{
  "scenario": "Patient is a 58-year-old male with acute chest pain radiating to left arm, BP 85/50.",
  "options": ["Administer IV Beta-Blockers", "Immediate Cardiac Catheterization Lab Activation", "Discharge with pain medication"],
  "preferred": "Immediate Cardiac Catheterization Lab Activation",
  "rejected": "Discharge with pain medication"
}
```

---

## How to Add Training Data

1. Open `train_dataset.jsonl` in any text editor
2. Append one JSON object per new line
3. Ensure `preferred` and `rejected` are both present in `options` and are not identical
4. Validation runs automatically in `load_jsonl_dataset()` in `training/trainingScript.py`

**Validation errors will look like:**
```
ValueError: Line 8 missing required field 'preferred'
ValueError: Line 9: 'preferred' ('X') not found in 'options'
```

## Used By
- `training/trainingScript.py` → `load_jsonl_dataset()`, `build_dpo_samples()`, `build_rlcd_samples()`
- `BPETokenizer.train_from_file()` reads `data.txt` (only if tokenizer not yet saved)
